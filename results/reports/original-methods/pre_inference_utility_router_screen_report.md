# 检测前效用排序路由开发筛选与关闭报告

> 工作包：`P12-PRE-INFERENCE-UTILITY-ROUTER`
> 日期：2026-08-08（Asia/Shanghai）
> 结论：seed0未超过固定岭回归图像统计基线；按预注册门停止，不运行seed1/2或正式检测评估

## 1. 目标与协议

历史P2特征路由必须先完成640检测后再对25%图像执行960，实际比全960慢4.61%。P12尝试把决策移到检测器之前：只读取`160×96`RGB缩略图，以连续small检测效用训练23,417参数CNN，并计划将图像互斥分配到640或960。

协议在训练前冻结于`docs/protocols/PRE_INFERENCE_UTILITY_ROUTER_PROTOCOL.md`。训练使用原BDD train中的5,000图，前4,000拟合、后1,000早停；500图互斥开发集只做最终阶段判定。损失固定为效用差加权成对排序加0.25倍标准化效用Smooth L1。开发门要求三个seed都超过最佳同成本图像统计基线，且中位相对增益至少5%。

本阶段没有读取BDD正式10k val，没有访问VisDrone test-dev，也没有启动检测器训练或推理。

## 2. 工程结果

- 缩略图CNN参数量：23,417，低于100,000上限。
- 输入与缓存：5,000 train / 500 dev，全部图像解码成功；效用范围分别为`[-27,57]`和`[-17,40]`。
- CPU真实数据smoke完成；CUDA seed0前向、反向、17轮训练、早停、序列化和开发打分全部有限。
- seed0最佳epoch为2；训练到epoch17后按patience15停止。
- 模块、缓存、checkpoint、报告和开发分数均记录SHA256，见`results/pre-inference-router-screen/summary.json`。

## 3. 开发结果

固定Top25%即125张图，开发Oracle效用和为1,655。

| 路由分数 | 选中效用和 | utility capture | Top25% target precision |
|---|---:|---:|---:|
| 哈希随机 | 325 | 0.19637 | 0.232 |
| 灰度标准差 | 419 | 0.25317 | 0.272 |
| 全局Laplacian | 532 | 0.32145 | 0.304 |
| 全局Sobel | 536 | 0.32387 | 0.296 |
| 上半区Laplacian | 505 | 0.30514 | 0.320 |
| 固定岭回归统计 | 679 | 0.41027 | 0.352 |
| 缩略图CNN seed0 | 602 | 0.36375 | 0.312 |

CNN明显超过随机和单一手工统计，但比只在前4,000图拟合的岭回归统计基线少捕获77点效用，utility capture相对低11.34%。训练loss从epoch1的0.7761降至epoch17的0.4864，但holdout utility capture没有同步提高，说明当前表示/目标优化并未形成更好的固定预算排序。

## 4. 决策

预注册门要求三个seed全部超过最佳图像统计基线。seed0已经失败，因此该条件不可能成立，工作包立即停止：

- 不运行seed1或seed2；
- 不访问BDD正式val；
- 不实现640/960互斥检测运行时；
- 不启动UAVDT、UA-DETRAC或其他外部数据；
- 不搜索缩略图尺寸、网络宽度、预算、回归权重或新损失；
- 不把CNN超过单一Sobel/Laplacian的结果写成有效方法，因为更强的同成本岭回归已经胜出。

这次结果仍提供一个有价值的工程结论：低成本图像统计对高分辨率效用具有可测关联，但当前神经路由没有证明其必要性。岭回归只能作为简单基线或后续独立研究假设，不能绕过本协议继续进入正式评估。
