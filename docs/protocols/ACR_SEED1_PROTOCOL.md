# ACR seed1 复制协议

> 冻结日期：2026-09-03（Asia/Shanghai），启动前写入。
> 状态：用户于2026-09-03授权启动多seed验证；GPU1，与RL任务共存（同seed0条件）。

## 1. 目的

检验ACR增益的跨seed稳定性：seed0已形成完整证据链（small AP 200轮同协议+7.28%、对官方+9.17%）；单seed是论文仅存的软肋。本复制用seed1回答"换一次训练随机性，增益方向是否一致"。

## 2. 冻结设计

- 配置：`configs/train/bdd100k-acr-s1-candidate-640-e200-b32.yaml`——与seed0候选`bdd100k-acr-r1-candidate-640-e200-stop20-b32.yaml`逐字段一致，仅三处不同：`seed: 1`、run名称、无`stage_stop_epoch`（直跑200轮）。
- 模型YAML、预训练权重、数据、调度、batch、device均不变。
- 与widen-only对照（GPU0并行）互不干扰；训练期间不运行任何计时基准。

## 3. 判定（预注册）

- **跨seed稳定**：seed1完整10k尺寸评估中，small AP相对R0-200冻结值（0.103266）为正，且相对幅度落在seed0的一半以上（即≥+3.6%）。此时论文可写"增益跨seed方向一致、幅度稳定"。
- **方向成立但幅度收缩**：small AP相对R0为正但<+3.6%——如实报告幅度区间，不挑数字。
- **方向反转（小概率）**：small AP低于R0——如实报告，ACR叙事回退为"seed0上成立、跨seed不稳定"，论文以seed0为主并披露。
- 无论哪种结果不追加seed调参、不改设计；seed2是否运行另行决策。

## 4. 禁止事项

- 不因中途曲线调整任何字段；不比较训练期在线曲线作结论（只认200轮完整10k尺寸评估）。
- 不与widen-only结果混用判定；两个实验回答不同问题（重分配必要性 vs 跨seed稳定性）。
