# PASCP道路小目标增强研究计划

> 冻结日期：2026-08-07（Asia/Shanghai）  
> 当前状态：公平Stage20核心门失败；路线关闭
> 基座：官方YOLO26n-P2-640；不改变推理网络、参数量、GFLOPs或推理速度

## 1. 研究问题

已有自研网络层与蒸馏方法均未通过完整数据门。BDD100K的小目标问题同时表现为目标像素少、类别分布不均和道路透视位置受限，因此本工作包转向训练时数据分布：在不改变已有效官方P2结构的前提下，受约束地增加可信小目标实例，能否同时提高small AP与small AR？

方法暂命名为PASCP（Perspective-Aware Small-object Copy-Paste，透视感知小目标复制粘贴）。它是自研训练时增强模块，不是推理网络层。如果学校或导师把“自研模块”严格限定为部署时网络结构，本路线即使有效也不能自动满足该措辞，必须事先确认。

## 2. 文献与现有实现边界

- Kisantal等通过重复含小目标图像并复制粘贴小目标改善COCO小目标检测，说明增加小目标出现频次是有实证基础的方向[@kisantal2019augmentation]。
- Li等在自动驾驶稀有目标中使用局部自适应变换和交通场景上下文约束，说明道路目标不能任意落点[@li2022traffic]。
- Siripathitti等指出道路损伤的随机粘贴忽略道路位置和透视关系，提出内容与透视感知增强[@siripathitti2024precision]。
- 当前Ultralytics `CopyPaste`依赖实例分割轮廓；BDD本项目只有检测框，默认检测训练中该实现直接不生效。

因此，通用Copy-Paste、小目标复制、上下文约束和透视约束均不属于本文原创。若PASCP最终有效，本文仅主张以下组合实现与受控验证：面向纯框检测的同图小目标复制、图内逆频率类别采样、以目标底边为道路透视代理的垂直带约束、候选框遮挡拒绝，以及与YOLO26-P2完全相同推理图的实验结论。

## 3. 冻结算法

输入为Mosaic与随机仿射后的640像素训练图及绝对坐标检测框。每张图以概率`0.5`执行：

1. 仅把面积不超过图像面积`0.0025`且宽高均不少于2像素的框作为donor；该面积阈值等价于640输入上的32平方像素COCO-small边界。
2. 按当前图内small候选类别频次的倒数采样，最多选择3个不同donor，避免实例多的类别完全主导复制机会。
3. 保持donor宽高不变；新框底边只允许落在原底边上下图高`0.08`的带内，横向位置随机。
4. 新框与任一已有/新增框的intersection-over-candidate-area不得超过`0.20`；每个donor最多尝试20次，失败则跳过。
5. 从原图复制包含15%窄上下文边界的矩形块，边缘最多3像素线性羽化；只追加目标框和原类别。
6. 仅支持检测框；分割、姿态或归一化坐标输入保持不变。标准`close_mosaic`阶段同步关闭PASCP。

不使用外部分割模型、生成模型、BDD场景元数据或跨图donor库，避免引入额外数据和无法隔离的变量。所有随机选择使用Ultralytics已统一设种的Python随机源。

## 4. 实验矩阵与停止门

### 4.1 工程门

必须先通过：默认关闭零回归、确定性逐像素一致、框/类别数量一致、small-only、尺度保持、垂直带、遮挡阈值、配置类型与流水线注册测试；再完成固定400/100子集3 epoch smoke，要求无OOM、NaN/Inf、损坏框和数据加载异常。smoke指标不得进入论文结果。

### 4.2 公平Stage 20

- R0：官方YOLO26n-P2-640，`pascp=0.0`。
- R1：同一官方模型与权重，仅改`pascp=0.5`。
- 两组均为完整BDD train、seed0、batch32/nbs64、相同200 epoch学习率计划，在epoch20保存完整optimizer/scaler/EMA后暂停。
- 两组best对同一完整10k val执行独立验证和small/medium/large尺寸评估。

R1只有同时满足以下门槛才可进入Stage40：small AP相对提升至少5%；small AR为正；all AP相对下降不超过2%；medium和large AP均不得下降超过5%；训练健康且推理成本与R0相同。

### 4.3 禁止搜索

本轮只验证上述单一冻结版本。不得根据Stage20结果搜索执行概率、复制数量、面积阈值、垂直带、重叠阈值、羽化宽度或流水线位置。Stage20失败即关闭；通过后才允许按同一配置恢复至Stage40，并在最终完整训练后进行至少三seed和组件消融。

## 5. 当前判定

PASCP已完成工程门、R0/R1完整BDD公平Stage20和10k尺寸评估。相对官方P2，all AP下降1.32%，small AP下降3.70%，small AR下降6.42%，medium AP基本持平，large AP下降1.86%。small AP至少+5%和small AR正提升两项核心门均失败，因此路线关闭，不进入Stage40、200轮、多seed或参数搜索。完整报告见`results/reports/original-methods/pascp_stage20_report.md`。
